# Деплой api

Деплой — это **новая версия функции с конфигом текущей**: рантайм, память, сервисный аккаунт,
переменные и привязки Lockbox копируются с живой версии, меняется только код и то, что ты
переопределил явно. Terraform в `infra/` — документация, а не путь выката: стейта нет ни на одной
машине, `apply` из пустого стейта попробует **создать** базу с чужими партиями.

## 1. План — сначала сухой прогон

```bash
bash scripts/deploy.sh --dry-run
```

Читать весь вывод, а не «ok». В плане обязаны быть:

- все переменные окружения (с пометкой `+` у новых из `deploy.env`);
- **все** привязки Lockbox — и скопированные с живой версии, и добавленные через `deploy.secrets`.

Если ожидаемой строки в плане нет — **в прод она не уедет**. Так один раз тихо потерялись две
привязки: скрипт их отправлял, но не печатал.

## 2. Переменные и секреты

- `deploy.env` — `KEY=value`, перекрывает живое значение. Gitignored, **машинно-локальный**.
- `deploy.secrets` — `ENV_VAR=secretId:key`, привязка к **текущей** версии секрета Lockbox
  (скопированные с живой версии остаются приколоты к своей — это намеренно).
- Секрет создавать так, чтобы значение никогда не попало в лог: записать во временный файл,
  скормить `yc lockbox secret create --payload`, файл удалить. **Одной командой** — между вызовами
  Bash временные файлы могут не пережить песочницу.
- Проверять права: рантайм-аккаунту функции нужен `lockbox.payloadViewer` на секрет или папку.

**На новой машине `deploy.env` и `deploy.secrets` придётся создать заново**, иначе деплой молча
выключит то, что от них зависит (почтовые оповещения, например, инертны без всех переменных).

## 3. Схема YDB — до выката кода

```bash
npm run migrate   # идемпотентно; нужен YDB_ENDPOINT/YDB_DATABASE + YDB_ACCESS_TOKEN=$(yc iam create-token)
```

Порядок при смене схемы: миграция → деплой api → фронт. Иначе новый код придёт в старую таблицу.
Токен IAM живёт недолго — `Unauthenticated`/transport 16 на локальном стенде означает просто
просроченный токен.

## 4. Выкат

```bash
bash scripts/deploy.sh
```

Если запуск блокируется классификатором — попросить пользователя выполнить его самому
(`! cd … && bash scripts/deploy.sh`), не искать обход.

## 5. Смоук (без него деплой не закрыт)

```bash
curl -s https://api.wh-rules.ru/health
```

И обязательно **круг по тому, что менялось**: новый роут вызвать по-настоящему, запись прочитать
обратно из базы (`npm run feedback:list`, `npm run games:list`-эквивалент, скрипт под задачу).
`200 OK` без проверки данных — не доказательство.
